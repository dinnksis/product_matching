# Локальные данные

Parquet-файлы соревнования не коммитятся в Git. Для текущего EDA ожидаются:

| Файл | Строк | Поля | Назначение |
|---|---:|---|---|
| `items_human.parquet` | 711 304 | `id`, `name`, `attributes`, `category` | Карточки, участвующие в ручной разметке |
| `matches.parquet` | 365 654 | `id1`, `id2`, `target` | Ручная разметка пар |

`attributes` — валидная JSON-строка с неодинаковой схемой в разных категориях.
`target` принимает значения `0.0` и `1.0`. Все пары находятся внутри одной из
20 категорий.

Когда будет скачана LLM-разметка, её стоит положить сюда под отдельными именами,
не смешивая с human labels. До обучения нужно зафиксировать происхождение метки,
удалить повторы пар и проверить конфликты с ручной выборкой.
