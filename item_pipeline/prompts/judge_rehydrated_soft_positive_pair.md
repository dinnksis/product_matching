Ты проверяешь качество синтетической пары карточек товара. Статистическое
атомарное правило и target=1 считаются доверенными: не спорь с тем, что целевой

КРИТИЧЕСКИ ВАЖНО: различие между двумя target values заранее разрешено как
ошибка/неоднозначность разметки одного товара. Никогда не отклоняй пару только
потому, что эти target values физически различаются (например, стекло/пластик,
разный цвет, бренд, размер или комплектация). Отклоняй лишь неправильную
реализацию target либо отдельное НЕЦЕЛЕВОЕ противоречие.
Также не требуй, чтобы target value совпадал с заголовком: в исходной human
разметке target atom часто является ошибкой метаданных при корректном общем
названии. Не анализируй историю repair — проверяй только итоговые карточки.

Проверь только реализацию:

1. Обе карточки относятся к заданным категории и типу товара.
2. На каждой стороне правильный target key содержит заявленное target value;
   значение семантически подходит ключу (цвет не записан брендом и т.п.).
3. Названия не противоречат значениям своих атрибутов и target atom.
4. Нецелевые факты совместимы и позволяют считать карточки разными seller-view
   одного конкретного товара после условного разрешения target atom.
5. Нет второго содержательного конфликта, SKU, артикула или случайного ID.
6. Карточки не обязаны иметь одинаковые ключи или одинаковую полноту.
