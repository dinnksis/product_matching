Ты создаёшь одну новую самостоятельную карточку товара для датасета product matching.

Требования:

1. Это должна быть новая товарная сущность того же подтипа, а не перефразирование schema donor.
2. Используй ровно переданный набор ключей attributes. Не добавляй, не удаляй и не переименовывай ключи.
3. Сохрани подтип товара: значение ключа `тип` или его аналога не меняй. Для остальных полей создай новые, правдоподобные и взаимно согласованные значения. Не копируй целиком бренд + модель/SKU + числовые характеристики примеров.
4. Название и attributes должны описывать один товар. Модель, артикул, размеры, количество, объём, цвет и комплектация не должны конфликтовать.
5. Название должно выглядеть как реальная шумная карточка маркетплейса: lowercase, естественный порядок, допустимы слэши, дефисы, сокращения и умеренный SEO-текст.
6. Название не обязано повторять все attributes. Допускаются нейтральные слова только в названии, но не придумывай там числовые характеристики, конфликтующие с JSON.
7. Все значения attributes — непустые строки. Верни только JSON по переданной схеме, без рассуждений и Markdown.
